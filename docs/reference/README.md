## 4. 디자인 시스템

### 4.1 컬러
| 역할 | 값 | 쓰임 |
|---|---|---|
| Brand Blue | `#00479C` (rgb 0,71,156) | 아이브로우, 버튼, 아이콘, 링크 |
| Ink | `#111111` | 본문 제목, GNB, 푸터 배경 |
| Body Gray | `#505050` | 본문 텍스트 |
| Page BG | 연한 블루그레이 (~`#F4F7FA`) | 중간 섹션 배경 |
| Highlight Yellow | `#FFFF00` | 히어로 공지, 본문 형광펜 강조 |
| Accent Green / Red | 인포그래픽 내 초록(#1E7B34 계열), 빨강(#E53935 계열) | 이미지 안 타이틀 2색 |
| Purple | `rgb(128,26,175)` | 일부 강조 H2 (현장 맞춤형 기술) |
| 다크 섹션 | `#000` → 네이비 (지구 이미지) | 실적 카운터 |

팔레트는 **신뢰(블루) + 친환경(그린) + 경고/강조(레드·옐로)** 의 3축. 토큰화된 디자인 시스템이 없고 Elementor 개별 값으로 흩어져 있다 (Elementor global color는 WP 기본 프리셋만 잔존).

### 4.2 타이포그래피
- 본문/제목 전부 **Pretendard** (400/500/600/700/800). 영문 보조로 **Montserrat** (100–900) 로드되나 거의 미사용.
- 사이즈: H2 35px(히어로) / 25px(섹션) / 20px(아이브로우), 본문 22–22.5px (**매우 큼 — 시니어 타깃 가독성**), GNB 16–17px.
- 제목 weight 700, 본문 500 (일반적인 400보다 두껍다).
- 아이콘 폰트: `uicore-icons`.

### 4.3 기타 토큰
- `--brand-round: 6px`, `--button-height: 36px`, `--transition-time: .3s`
- 버튼 radius 6–10px, 카드는 거의 각진 사각 + 이미지 풀폭
- 컨테이너 ≈ 1197px (좌우 패딩 ~42px)
- 모션: Elementor `fadeInUp`, `slideInUp`, Motion FX, 카운터 카운트업, Element Pack 배경 패럴랙스

## 6. 약점 / 개선 포인트 (리디자인 관점)

1. **섹션 3이 7,600px짜리 이미지 덩어리** — 텍스트가 이미지에 구워져 있어 SEO·접근성·번역·반응형에 불리. 실제 HTML 텍스트 + 아이콘/일러스트로 재구성 가능.
2. 이미지 용량 과다: `F100/S100/S200/진단` PNG 각 2.3–2.9MB, `지점모집공고.png` 3.4MB → WebP/AVIF 변환 시 90% 절감.
3. 이미지 alt가 "NST공법 새집증후군 개선 시공현장"으로 반복 / 갤러리는 alt 없음.
4. 히어로는 YouTube iframe이라 LCP/성능 부담. 포스터 + 지연 로드 권장.
5. 모바일 버전은 데스크톱 이미지를 그대로 축소 (`mobile-full-390.png` 참고).
6. 푸터 "One-tenth" 테마 크레딧, 구 도메인(mycafe24) 폰트 의존 잔존.
7. 신뢰 증빙(시험성적서, 환경부 신고)이 메인에서 시각적으로 약함 — 칼럼의 "증빙 허브"를 메인에 끌어올릴 여지.
8. 컬러 토큰/타입 스케일이 없어 일관성은 이미지 의존.
