안녕하세요. (주)엔에스티입니다. 오늘은 특별한 소식을 전해드립니다.

​

(주)엔에스티 NST공법의 얼굴이자,

상징인 “NST새지비” 캐릭터가 드디어 공식 홍보대사로 런칭했습니다!

\
NST새지비는 새집+비전(vision) : 미래 세대를 위한 건강한 주거 비전 의미로 (주)엔에스티 NST공법을 대표하는 홍보대사이자

친환경 지식을 공유하며 미래의 주거 문화를 만들어갈 비전의 상징입니다.”
