# 회사소개

홈 · 회사소개 · 연혁

실내공간의 환경을 디자인하다.\
새집증후군 예방 - NST 3단계 솔루션!
-----------------------------------

㈜엔에스티는 자연과 과학기술(Natural Science&Technology)을 융합하여 건강한 실내공간을 만드는 기업입니다.\
2009년 창립 이후, 직접 연구개발·제조·판매하며 신축 아파트 등 실내공간의 실질적인 공기질 개선 솔루션을 제공해왔습니다.
