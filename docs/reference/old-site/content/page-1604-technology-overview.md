## 

### NST공법 – 20년 노하우가 집약된 상온경화 코팅 솔루션

![대형배너(2026) -1 관련 자료](https://knst.co.kr/wp-content/uploads/2026/01/대형배너2026-1.jpg)

## 

### 

국내 최초로 대형건설사 아파트 전 세대 일괄시공(1,018세대 외 다수)으로 검증하고 발전시켜 온 20년 노하우 집약 기술입니다.\
\

보여주기식 퍼포먼스와 단순 탈취가 아닌 과학적 원리에 기반해 새집증후군 유발 물질을 근본적으로 제거합니다.

\

🏆 환경부 후원 「2025 대한민국환경대상」 환경제품 부문 수상 – 국민 건강 기여와 기술력 공식 인정

\

\[1단계\] : 하이앤드 듀얼 정착(NST-S200) : "유해물질 제거 동시에 방출원 구조를 안정화"\

가구 및 목재 오염원에 침투하여 방출되는 포름알데하이드와 VOCs의 확산을 억제하고 구조적으로 안정화 시킵니다.\
\
→ **투명막 형성 + 친환경 원료 기반**으로 가구 기능에 영향을 주지 않으면서 유해물질이 배출되지 않도록 안정적인 구조를 만듭니다.

- 

  \[2단계\] : 하이앤드 듀얼 케어(NST-F100) : "공기 흐름이 정체되기 쉬운 공간의 사각지대에서 유해물질 제거 보조"\

  안전한 친환경 천연물질로 고객님의 체감 쾌적성과 만족도를 높입니다.\
  \
  → 어두운 공간에서도 반응하면서 은은한 **천연 숲향(솔향)**을 제공합니다.

## 

### 

\[3단계\] : 하이앤드 듀얼 촉매(NST-S100) : "환경 조건에 따라 작동 방식이 자동으로 전환하며 유해물질을 제거"\

빛이 없는 환경에서도 유해물질을 끌어당겨 포집하고 자연광이나 실내 조명이 확보되면 제거합니다.\
\
→ **햇빛과 실내조명만으로도 지속 분해**되며 자가세정(Self-Cleaning) 기능으로 오염물질을 반복 제거합니다.
